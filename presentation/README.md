# Project Presentation

Contents:

- `Slides.md` — Slide deck for presenting the project.
- `architecture.mmd` — Mermaid architecture diagram.
- `demo.md` — Live demo runbook and commands.
- `run-local.ps1` — Convenience PowerShell script to start the main Docker Compose stack.
- `checklist.md` — Short checklist for the demo.

How to use

1. Open `Slides.md` in your editor or convert to reveal.js slides.
2. Follow `demo.md` to start the demo environment (Docker Desktop required).
3. Use `architecture.mmd` during the Architecture slide.
4. Run `presentation\\run-local.ps1` (Windows PowerShell) to start services.

Prerequisites

- Docker Desktop (or equivalent) and `docker compose` available.
- Optional: `kubectl` if you plan to demo Kubernetes manifests.

If you want, I can (a) run the stack here, (b) generate a PDF of slides, or (c) tailor slides for a specific audience.
